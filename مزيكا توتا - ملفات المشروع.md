## 10) `supabase-schema-final.sql`
```sql
create table if not exists songs (
  id bigint generated by default as identity primary key,
  title text not null,
  artist text,
  audio_url text,
  cover_url text,
  created_at timestamp with time zone default now()
);

create table if not exists settings (
  id bigint generated by default as identity primary key,
  key text unique not null,
  value text,
  created_at timestamp with time zone default now()
);
```

## 12) `دليل تجهيز ورفع الملفات.md`
```md
# دليل تجهيز ورفع الملفات

1. ضع كل الملفات في مجلد واحد.
2. افتح `index.html` للتجربة المحلية.
3. ارفع الملفات على الاستضافة.
4. تأكد من وجود ملفات الصفحات والـ redirects.
5. اربط قاعدة البيانات إذا لزم.
```
