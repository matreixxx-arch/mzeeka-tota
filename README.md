# مزيكا توتا

موقع موسيقى عربي بواجهة فخمة وليلية بألوان وردية-بنفسجية.

## الملفات الأساسية
- `index.html`
- `songs.html`
- `player.html`
- `admin.html`
- `vercel.json`
- `_redirects`
- `deployment-config.json`
- `README.md`

## أين تضع الملفات
ضع كل الملفات في **جذر المشروع** مباشرة، بدون أي مجلدات إضافية.

## تشغيل المشروع
- افتح `index.html` في المتصفح للاختبار السريع.
- عند الرفع على GitHub، ارفع الملفات كلها كما هي في الجذر.
- اربط المشروع مع Vercel إذا أردت النشر المباشر.

## مسارات الموقع
- `/`
- `/songs`
- `/player`
- `/admin`

## Supabase
المشروع يعتمد على:
- **Supabase Auth** للوحة الإدارة
- **Supabase Storage** لملفات الأغاني والأغلفة

## الجداول المطلوبة
### `songs`
- `id`
- `title`
- `artist`
- `cover`
- `audio`
- `plays`
- `downloads`
- `createdAt`

### `song_metrics`
- للتتبع والإحصاءات

## Buckets
- `song-covers`
- `song-audios`

## النشر
1. ارفع الملفات إلى GitHub.
2. اربط المستودع مع Vercel.
3. تأكد أن المسارات تعمل بشكل صحيح.
4. اضبط Supabase على الجداول والبكتات المطلوبة.

## ملاحظة
إذا احتجت ترتيب الملفات أو خطوات الرفع، ابدأ من الجذر ثم ارفع كل شيء كما هو.
